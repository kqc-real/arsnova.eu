# Materialindex Cloud Computing

**Kürzel und Fachkürzungen vorab:** **A11y** bezeichnet Barrierefreiheit (Accessibility), **ADR** einen Architecture Decision Record, **AWS** Amazon Web Services, **DNS** das Domain Name System, **ETL/ELT** Extract, Transform, Load beziehungsweise Extract, Load, Transform, **FinOps** Financial Operations, **GCP** Google Cloud Platform, **IAM** Identity and Access Management, **IaC** Infrastructure as Code, **IU** die IU Internationale Hochschule, **JSON** JavaScript Object Notation, **LE** eine 90-minütige Lerneinheit aus zwei **UE**, **LI** einen Learning Indicator, **MC** Multiple Choice, **ML** maschinelles Lernen, **MLOps** Machine Learning Operations, **MZ** ein operationalisiertes Modulziel, **QA** Qualitätssicherung, **QZ** ein offizielles Qualifikationsziel, **RPO/RTO** Recovery Point Objective und Recovery Time Objective, **SHA-256** den Secure Hash Algorithm mit 256 Bit, **SLI/SLO** Service Level Indicator und Service Level Objective, **SRE** Site Reliability Engineering, **TB01–TB12** die zwölf stabilen Themenblöcke, **TCO** Total Cost of Ownership, **TLS** Transport Layer Security und **UE** eine 45-minütige Unterrichtseinheit. **6R** bezeichnet Rehost, Replatform, Repurchase, Refactor, Retire und Retain. **LIVE** bezeichnet im Kursbetrieb entstehende Interaktionsdaten, **REPO** versionierte Repository-Nachweise und **LEHRDATEN** synthetische oder ausdrücklich für die Lehre freigegebene Daten.

**Version:** 1.0.0 · **Stand:** 14.09.2026 · **Status:** kanonischer Soll-Index; Existenz oder Freigabe wird durch eine Zeile nicht behauptet

## 1. Zweck, Umfang und Kanonizität

Dieser Index beschreibt den vollständigen Sollbestand des neuen Modulpakets unter `docs/didaktik/Modulkonzept Cloud Computing/`. Die Zielgruppe besteht ausschließlich aus Bachelorstudierenden der Informatik. Der Index nennt für jede der 41 erwarteten Repository-Dateien Zweck, verantwortliche Rolle, Einsatz, Transformation von Eingabe zu Ausgabe und Abnahmekriterium.

Die frühere Konzeption steuert das neue Paket nicht. Vollständig konsolidierte Altdateien wurden entfernt; noch nicht vollständig migrierte Detaildokumente bleiben über die [Bestandsaufnahme des Altmaterials](./Bestandsaufnahme_Altmaterial.md) nachvollziehbar. Für den neuen Kurs gelten in dieser Reihenfolge:

1. [Modulkonzept](./Modulkonzept_Cloud_Computing.md) für Rahmen, Ziele und Themenblockaufbau;
2. [Lernziel- und Alignment-Matrix](./Lernziel_Alignment_Matrix.md) für QZ, MZ, LI und Constructive Alignment;
3. der [Themenblockplan](./Themenblockplan_Cloud_Computing_12_Themenbloecke.md) für Inhalte, Lerneinheiten, Fachwortschatz und Lernprodukte;
4. der [Referatsthemenkatalog](./Referatsthemen_Cloud_Computing_ARSnova.md) für die zehn prüfungsbezogenen Fallstudienaufträge;
5. die beiden Blueprints für die normativen Fragenverträge;
6. die 24 Themenblock-JSONs als autoritative Wortlaut-, Options- und Lösungssätze;
7. [Lehrenden-Runbook](./Lehrenden_Runbook.md) und [Datenmanagement](./Datenmanagement_Datenschutz.md) für Betrieb und Datenlebenszyklus;
8. [QA-Freigabeprotokoll](./QA_Freigabeprotokoll.md) für reale Prüfergebnisse und offene Gates.

Laufzeitexporte, personenbezogene Rohdaten, Agentenprotokolle mit Secrets, Produktionsdaten, Datenbankkopien und echte Zugangsdaten gehören nicht in dieses Paket.
