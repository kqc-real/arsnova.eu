# Session-Host Live-Chrome

- Canonical style contract: `docs/ui/STYLEGUIDE.md` → **Style-Vertraege** → _Host-Live-Zeile, Icon-Buttons und Kapseln_. Checklist: `docs/ui/PR-CHECKLIST-UI.md` section 4. Related: `mem:frontend/core`, `mem:frontend/i18n-ui`.
- **Fluchtlinie:** `.session-host__live-shell-row`, `.session-channel-tabs-shell`, and `.session-host__channel-panel` share `--session-host-shell-width` + `max-width: 100%` + `margin-inline: auto`. Do not set the live row to `width: 100%` on mobile; that pulls the join pill and compass off the tab/card edges.
- **Compact join pill:** `.session-host__live-banner` is `width: max-content` / `flex: 0 1 auto`. Do not use `flex: 1` or Channel-Tabs `width: auto` to fill the gap to the compass. QR trigger is icon-only (`qr_code_2`); visible “Beitritt” is gone; keep `aria-label` `@@sessionHost.joinControlAria`. Compass stays on the right (`space-between` under 600px).
- **Large `mat-icon-button`:** Material uses `display: inline-block` and centers via `padding: calc((--mat-icon-button-state-layer-size - --mat-icon-button-icon-size) / 2)`. Setting only `--mdc-icon-button-state-layer-size` and `padding: 0` leaves the glyph off-center in the focus/hover disk (baseline gap). Set both `--mat-icon-button-*` tokens and `inline-flex` + `align-items/justify-content: center`. Touch target ≥ 44px. Same pattern on standalone feedback join.
- **Icon+text chips** (e.g. `.session-host__vote-dist-correct`): `align-items: center`, wrap the label in a `span`, no `margin-top` on the icon. `flex-start` parks single-line body text at the top of the pill.
- References: `apps/frontend/src/app/features/session/session-host/session-host.component.{html,scss}`, `apps/frontend/src/app/features/feedback/feedback-host.component.{html,scss}`.
